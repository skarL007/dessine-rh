# Dessine RH · Demonstração

Versão pública de consulta, com dados fictícios e prévia da folha calculada no navegador.

- Instale com `npm ci` e execute `npx vite` para abrir o painel localmente.
- Para publicar na sua Vercel, importe o repositório e escolha a branch `demo` como branch de produção. O arquivo `vercel.json` configura o build estático.
- A branch `main` contém a aplicação completa, com autenticação e PostgreSQL. Leia o README daquela branch para instalar o sistema com seu próprio banco.

A demonstração funciona sem login e sem variáveis de ambiente.
